# Public Roadmap

Policy Forge roadmap themes are public direction, not private commitments.

## Near Term

- Stronger control history
- Regression alerts
- Richer authorization package export
- Improved AI assistance with human review
- Air-gapped LLM integration
- Deeper scanner integrations
  - Now available: AWS Security Hub, Inspector, and GuardDuty findings map to controls (RA-5 for Inspector, SI-4 for GuardDuty, and NIST mappings when AWS provides them) and get stable identities.
  - Current limitation: findings resolved in AWS do not yet close automatically.
- Executive drill-down views

## Guiding Principle

Roadmap work should keep security remediation fast and compliance evidence defensible.
